# CredSaathi AI Auditability & Telemetry Specification

## 1. Overview

The CredSaathi AI Auditability Layer ensures full observability, governance, and traceability across all AI agent dispatches, model invocations, retrieval events, and guardrail validations without compromising privacy or storing sensitive user payloads.

---

## 2. What Is Logged

Each AI operation generates a structured `AIAuditRecord` tracking key operational metadata:

| Field Category | Logged Attributes |
| :--- | :--- |
| **Correlation & Identity** | `request_id`, `user_id` (scope identifier), `application_id` (context ID) |
| **Task Classification** | `task_type` (e.g. `SCHEME_MATCHING`, `DOCUMENT_EXTRACTION`, `CUSTOMER_ASSISTANT_QUERY`) |
| **Model Metadata** | `model_provider`, `model_name`, `model_version`, `prompt_template_version` |
| **Grounding & Tools** | `retrieval_source_ids` (chunk IDs), `tool_calls` (tool name, trace ID, execution status) |
| **Performance & Cost** | `latency_ms`, `prompt_tokens`, `completion_tokens`, `total_cost_usd` |
| **Validation & Security** | `output_validation_status` (`PASSED`, `REPAIRED`, `REJECTED`), `guardrail_events`, `errors` |
| **Compliance & Escalation** | `human_review_required` (boolean flag), `timestamp` |

---

## 3. What Is Intentionally NOT Logged (Data Minimization)

To comply with privacy regulations and data minimization standards, the AI Service explicitly **excludes**:

1. **Raw User Prompts & Transcripts**: Free-form user inputs that may contain PII or unredacted financial queries are not stored in audit records.
2. **Raw Model Outputs**: Direct text generated by models is excluded; only validation status (`PASSED`/`REPAIRED`), guardrail flags, and token counts are recorded.
3. **Document Payloads & Binary Bytes**: Uploaded PDFs, images, or extracted raw text blobs are excluded from audit records.
4. **Authentication Credentials & Tokens**: User session tokens, API keys, and internal secrets are strictly stripped.

---

## 4. Retention Considerations

- **Hot Audit Store (In-Memory / Logs)**: 7 days retention for real-time debugging, alerting, and operational dashboards.
- **Cold Compliance Store (DB Persistence via Sink)**: 90 days to 1 year retention for compliance audits, financial reporting, and model performance analytics.
- **PII Scrubbing**: Any logs exported to secondary storage must pass through `PrivacyGuardrail.redact_pii()`.

---

## 5. How Engineers Can Trace an AI Request

1. **Obtain the Correlation `request_id`**: Every request entering the AI Gateway has a header/context ID `X-Request-ID` or generated correlation ID.
2. **Querying Audit Logs via `AuditService`**:
   ```python
   from ai.audit import audit_service

   records = audit_service.get_in_memory_records(request_id="req_xyz123")
   for rec in records:
       print(rec.task_type, rec.model_name, rec.latency_ms, rec.output_validation_status)
   ```
3. **Correlating Agent Firewall Traces**:
   - `AIAuditRecord.tool_calls` links directly to `audit_trace_id` generated during firewall interceptor checks (`AgentFirewall.execute_tool()`).
4. **Inspecting Structured Logs**:
   Search stdout logs for standard tag prefix `[AI_AUDIT_EVENT]` or `[req_id:<request_id>]`.
